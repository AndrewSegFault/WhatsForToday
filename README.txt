WHAT'S FOR TODAY? - ANDROID PROJECT

Features:
- Add meals and remove meals.
- Randomly choose a meal from the current list.
- Automatically save the food list on the device using Android SharedPreferences.
- Restore the list and the last selected meal after reopening the app.
- Works offline. No account or internet permission is required.

BUILD AN APK:
1. Install Android Studio on a computer.
2. Extract this ZIP.
3. In Android Studio, choose Open and select the extracted WhatsForToday folder.
4. Let Gradle sync and install the Android SDK Platform 35 if prompted.
5. Select Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio will show the APK location (normally app/build/outputs/apk/debug/app-debug.apk).

The APK itself is not included: this environment does not have the Android SDK/build tools needed to compile and sign it.
